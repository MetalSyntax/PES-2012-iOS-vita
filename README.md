# PES 2012 (iOS) for PS Vita

Work-in-progress port of the iOS version of PES 2012 (v1.0.2) to the PS Vita, using a custom Mach-O
loader and Objective-C runtime. Not playable yet: it has not been run on hardware.

You need your own legally obtained IPA. No game files are included in this repository.

README is in progress.
